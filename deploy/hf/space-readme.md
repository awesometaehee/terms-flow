# KMS 현업 검토용 (임시)

약관·상품설명서 KMS를 현업이 검토하기 위한 **임시 배포**입니다. 모든 데이터는 `[샘플]` 가상 데이터입니다.

- 접속: 이 페이지가 아니라 **앱 주소(`https://<사용자>-<space>.hf.space`)** 로 직접 엽니다. 로그인 창이 뜨면 받은 검토용 계정으로 로그인합니다.
- 한동안 접속이 없으면 잠들고, 처음 열 때 1~2분 깨어나는 시간이 걸립니다.

이 저장소는 GitHub 저장소에서 자동으로 만들어집니다. 여기서 직접 고치지 않습니다.
